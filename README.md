# Grelqa

Первый каркас движка анонимных литературных конкурсов: Next.js App Router, React и TypeScript. Интерфейс на русском языке, адаптирован для телефона. Шрифты системные, внешние сервисы для отображения не требуются.

## Установка и запуск

Нужны Node.js **26.13.0** (зафиксирован в `.nvmrc`) и npm. Проверены требования пакетов: Next.js 16.4.3 требует Node.js >=20.9.0; ESLint 10.14.0 — ^20.19.0, ^22.13.0 или >=24; TypeScript 5.9.3 — >=14.17. Выбранная версия Node.js удовлетворяет этим требованиям. Изначальный Node.js 20.18.2 не подходит для актуального ESLint и его вложенных зависимостей.

```bash
nvm install
nvm use
npm ci
npm run dev
```

Откройте http://localhost:3000. Если nvm не установлен, установите соответствующую версию Node.js другим способом.

## Проверки и производственный режим

```bash
npm run check
npm run build
npm start
```

`check` запускает ESLint и TypeScript. `build` собирает приложение и генерирует страницы демонстрационных конкурсов. Для отдельной проверки доступны `npm run lint` и `npm run typecheck`. `npm start` требует предварительной сборки.

## Что доступно

- `/` — список трёх вымышленных конкурсов.
- `/contests/letters-to-november`, `/contests/city-between-lines`, `/contests/winter-notebook` — тема, условия, расписание и текущий этап.
- Неизвестные адреса возвращают страницу 404.

Данные находятся в `src/lib/contests.ts`, не сохраняются и не требуют базы. Текущие этапы зафиксированы вручную: течение времени их не меняет. У будущего конкурса публичной темы нет даже в исходных данных. Все даты и ограничения — вымышленные параметры примеров, а не новые общие правила. Время отображается в МСК независимо от часового пояса компьютера.

Аутентификация, SQLite, подача и чтение произведений, голосование, автоматические переходы этапов пока не реализованы. Форм-заглушек нет.

Принятые требования и открытые вопросы: [docs/grelqa_rules_and_spec.md](docs/grelqa_rules_and_spec.md). Разделы с предложениями не считаются согласованными решениями. Установка Next.js: https://nextjs.org/docs/app/getting-started/installation.
