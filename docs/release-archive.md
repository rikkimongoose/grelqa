# Grelqa: содержимое релизного архива

Архив рассчитан на Ubuntu 24.04 x86-64 и Node.js 26.13.0. Устанавливать npm-пакеты и выполнять `next build` после распаковки не нужно. Node.js в архив не входит.

Перед запуском задайте runtime-переменные окружения. `DATABASE_URL` должен быть абсолютным локальным `file:` URL к базе вне каталога релиза, например `file:/srv/grelqa-data/grelqa.db`. Аналогично вынесите `MAIL_DIRECTORY` и `EXPORT_CACHE_DIRECTORY`. Полный список и ограничения приведены в `docs/deployment.md` и `.env.example`; не храните реальный `.env` внутри релиза.

Основные команды из корня распакованного каталога:

```bash
bin/grelqa migrate
HOSTNAME=127.0.0.1 PORT=3000 bin/grelqa server
bin/grelqa schedule
bin/grelqa exports-clean
bin/grelqa help
```

Перед каждой миграцией остановите сервер и worker и сделайте согласованную резервную копию SQLite вместе с её WAL-состоянием. Не копируйте только `.db` у работающего приложения. Старый релиз приложения нельзя считать безопасным откатом после необратимого изменения схемы; сохраняйте и проверяйте резервную копию.
